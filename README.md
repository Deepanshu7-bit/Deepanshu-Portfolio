# Deepanshu Dhingra — Premium Full-Stack Developer Portfolio

A high-end, conversion-focused personal portfolio website engineered for **Deepanshu Dhingra** (Full Stack Developer · Mohali, Punjab, India).

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, SSR, Server Components)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict mode, zero `any`)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom CSS Variable Design System
- **Motion & Interaction**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Space Grotesk, Inter, JetBrains Mono, Cormorant Garamond

## ✨ Key Features

- **Two Complete Visual Directions**:
  - **Obsidian (Creative Dark)**: Deep black & charcoal backgrounds, electric blue/violet accents, precision vector geometries, and smooth cursor dynamics.
  - **Ivory (Minimal Luxury Studio)**: Warm ivory paper tones, rich charcoal typography, Cormorant Garamond serif headlines, and editorial magazine whitespace.
- **Interactive Theme Customizer Drawer**:
  - Live real-time controls for Theme (Obsidian / Ivory), Accent color (Blue, Violet, Orange, Green), Motion profile, Canvas texture (Grain, Grid, Solid), and Cursor mode.
  - Automatic `localStorage` persistence with 1-click Reset.
- **Selected Work**:
  - **CapGro Finex**: Multi-vertical loan & mutual fund distribution platform with zero customer fees.
  - **Prime Arc Studio**: Contemporary interior architecture & spatial design showcase with CAD vectors.
  - **Arya Dental Care**: Super-speciality dental clinic platform with digital appointment workflows.
  - **Arrive Hotels**: Boutique hotel platform across 5 US destinations by Palisociety.
  - **Supreet Insurance**: Independent Canadian insurance brokerage & wealth advisory platform.
  - **Nugen Atria**: Cloud-native hotel management OS (PMS) & guest mobile ordering SaaS.
- **View Mode Switcher & Category Filters**:
  - Grid View & Listing View options.
  - Interactive filter pills (Fintech, Architecture, Healthcare, Hospitality, Commercial, SaaS).
- **Interactive Tech Stack Constellation**:
  - Central `FULL STACK` hub with orbiting categories (Frontend, Backend, Databases, State, Cloud, Tools).
- **Engineering Capabilities**:
  - 6 cards with bespoke SVG illustrations representing product experiences, APIs, real-time systems, performance, and cloud.
- **Experience Timeline**:
  - 4-year progression across high-growth verticals.
- **Conversion-Focused Contact Section**:
  - Direct email with one-click copy toast notification.
  - Full client-side validated project inquiry form with loading and success states.

## 🛠️ Local Development

```bash
# Clone the repository
git clone git@github.com:Deepanshu7-bit/Deepanshu-Portfolio.git

# Navigate to project
cd Deepanshu-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
